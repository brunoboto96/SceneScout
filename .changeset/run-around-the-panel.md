The guided panel's run around it, in the optional Claude Code mod. While a guided check runs, a band above the prompt and the status line say what it is doing now and how many problems it has found, or what it needs from you, so the panel can be closed; a Claude Code build without the band or the status line keeps the panel as it was. Cards take **Not a bug** or **Confirmed** from the list of problems and from the card, both recorded through `scout_feedback`. And a saved check can be queued while another runs: queued checks start one at a time when the running one ends, each on a plan of its own in the care level it was queued with, confirmed by the person again where that care level needs it, and not started at all if its care level changed in the meantime.
