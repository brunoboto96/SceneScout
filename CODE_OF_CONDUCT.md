# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and
not the person, and no harassment of any kind. This applies in issues, pull
requests, discussions and anywhere else the project is represented.

## Reporting

If someone's behaviour here is a problem, report it privately to the
maintainer, [@brunoboto96](https://github.com/brunoboto96), through the contact
options on that GitHub profile, or use GitHub's own **Report content** link on
the comment or profile in question. Reports are kept confidential.

The maintainer may remove, edit or reject comments, commits, code, issues and
other contributions that do not follow this Code of Conduct, and may
temporarily or permanently block a contributor for behaviour they consider
inappropriate, threatening, offensive or harmful.
